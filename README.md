# 今日收入 · 菜单栏工资计数器

一个简约的 macOS 菜单栏小工具：细椭圆里显示今天已经赚到的金额，点击展开详情。

## 功能

- 菜单栏金额每秒重新计算，黑白配色自动适配系统外观。
- 点击展开今日收入、工作进度、上下班倒计时和薪资详情。
- 支持币种、月薪、上下班时间、工作日、每月计薪天数设置。
- 支持跨午夜班次；下班后停止增长，休息日显示零。
- 支持开机启动，初始关闭，可在详情的“更多”中开启。
- 设置仅存本机，无账号、无联网、无遥测，不占 Dock。

## 构建与运行

适用于 **Apple 芯片 Mac，macOS 14 或更新版本**。需要 Apple Command Line Tools 中的 Swift 编译器，无需完整 Xcode、开发者会员或第三方依赖。

```sh
./test.sh
./build.sh
```

构建产物：

- `build/今日收入.app`
- `build/今日收入-mac-arm64.zip`

将应用复制到“应用程序”后打开，从顶部菜单栏点击金额查看详情。首次启动会打开工资与作息设置。

构建脚本使用本机临时签名，未做 Developer ID 签名或 Apple 公证，适合自行构建使用。构建在临时目录完成，以避免文件提供程序附加 Finder 元数据干扰签名。

## 计薪规则

```text
日薪 = 月薪 ÷ 每月计薪天数
今日收入 = 日薪 × 已过的工作时段秒数 ÷ 当天工作时段秒数
```

默认月薪 5000、09:00–18:00、周一至周五、21.75 个计薪日，均为可修改的演示值。币种只改变单位，不换汇。不自动扣午休，不自动识别节假日。跨午夜班次归上班当天；设置改变后按新规则重新估算当天金额。这里的金额是估算，不代表实际发薪或到账。

## 数据与卸载

设置保存在本机 UserDefaults，应用 ID 为 `local.deskincome.card`。不上传工资，不读取银行或考勤数据。

卸载前如开启过开机启动，请从详情“更多”关闭，再退出并将应用移至废纸篓。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `Sources/IncomeModel.swift` | 作息设置、计薪与格式化 |
| `Sources/DesktopApp.swift` | 菜单栏椭圆、详情弹窗、开机启动与持久化 |
| `Sources/MenuBarViews.swift` | 点击后展开的详情界面 |
| `Sources/Views.swift` | 设置界面与保留的卡片视图 |
| `Tests/IncomeTests.swift` | 计薪边界、跨午夜、DST、输入验证等检查 |
