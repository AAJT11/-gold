# 今日收入 · 菜单栏 / Windows 状态栏 / Android 灵动胶囊工资计数器

由 hanmin6 设计的简约菜单栏工资计数器：细椭圆胶囊里显示今天已经赚到的金额，点击展开详情。仓库新增 **Windows 10/11 原生状态栏高定香槟金液态玻璃版** 与 **Android 状态栏灵动胶囊 + 桌面微件高定版（`android/`）**，完整保留原 macOS 源码与构建脚本。

---

## Android 高定灵动胶囊版 (`android/` 目录)

### 核心特性

- **状态栏悬浮灵动胶囊 (`FloatingCapsuleService`)**：基于 `SYSTEM_ALERT_WINDOW` 在手机顶部状态栏 / 挖孔区渲染高定黑曜石香槟金液态玻璃胶囊（`• ¥108.74`），支持任意位置拖拽磁吸，轻触即可唤起详情面板。
- **实时三位小数滚动看板 (`MainActivity`)**：同步采用 `MAISON · Luxury E-Commerce` 黑曜石深灰 (`#1C1917`)、暖雪花石膏白 (`#FAF9F6`) 与帝国香槟金 (`#D4AF37`) 设计系统，支持千分位末位动态滚动与香槟金流光进度条。
- **常驻状态栏/锁屏通知与桌面奢金微件 (`IncomeAppWidgetProvider`)**：支持锁屏与下拉通知栏实时查看今日累计收入、进度百分比及下班倒计时，并可将「今日收入 · 奢金桌面卡片」直接添加至手机桌面。
- **内置您的专属作息配置**：默认预设月薪 `¥5,000`、`09:00–18:00` 上下班、`12:30–14:00` 午休暂停计薪（按 `7.5h` 净工时精算时薪）、周一至周六工作（周日单休）及 `次月15日` 发薪日倒计时，支持在 App 内随时自定义修改。

### Android 版构建与安装

```bash
cd android
./gradlew assembleDebug
# 编译产物输出至: android/app/build/outputs/apk/debug/app-debug.apk
```

## Windows 状态栏版 (`windows` 分支)

### 核心特性

- **原生任务栏胶囊嵌入 (`Shell_TrayWnd` Owner 绑定)**：直接嵌入 Windows 顶部或底部状态栏托盘左侧（支持跟随托盘左侧、应用图标右侧、状态栏居中或自由拖拽磁吸），点击任务栏任意位置绝不闪烁或被遮挡。
- **高定黑金液态玻璃视效 (`MAISON · Luxury E-Commerce`)**：采用暖雪花石膏白 (`#FAF9F6`)、黑曜石深灰 (`#1C1917`) 与帝国香槟金 (`#D4AF37` / `#C5A059`) 配色体系，配合 `24px` 磨砂背景采样与金色流光进度条，自适应浅色/深色系统主题。
- **午休暂停与次月发薪日倒计时**：
  - 支持自定义午休时段（如 `12:30–14:00`），午休期间自动切换为「午休时间」并暂停计薪，按扣除午休后的净工作时长精算时薪。
  - 支持自定义工作日（如周一至周六工作、周日单休）与次月发薪日（如 `次月15日`），详情面板实时显示距发薪日天数倒计时。
- **开机自启与本机配置持久化**：所有配置保存在 `%APPDATA%\DeskIncome\config.json`，支持通过注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 一键开关开机自启。

### Windows 版构建与运行

```bash
pip install -r requirements.txt

# 运行单元测试
python test_income_model.py

# 直接运行
python main.py

# 打包为独立无黑框单文件绿色版 EXE (输出至 dist/今日收入.exe)
python build_exe.py

# 使用 Inno Setup 编译标准 Windows 安装包 (输出至 dist/今日收入-Windows-Setup-v1.0.0.exe)
iscc setup.iss
```

## macOS 菜单栏原版 (`main` 分支)

## 功能

- 菜单栏及详情中的今日收入显示三位小数（如 ¥12.345），每秒重新计算；第三位小数在计薪时快速连续向上滚动，第二位及更高位按真实金额平滑滚动；末位为视觉动效，不影响实际计薪，详情显示真实金额，黑白配色自动适配系统外观。遵循“减少动态效果”，金额不变化时停止动画。
- 点击展开今日收入、工作进度、上下班倒计时和薪资详情。
- 支持币种、月薪、上下班时间、工作日、每月计薪天数设置。
- 可启用午休、设置起止时间，并选择午休是否计薪。午休中显示返回工作倒计时。
- 支持跨午夜班次；下班后停止增长，休息日显示零。
- 支持开机启动，初始关闭，可在详情的“更多”中开启。
- 设置仅存本机，无账号、无联网、无遥测，不占 Dock。

## 构建与运行

适用于 **Apple 芯片 Mac，macOS 14 或更新版本**。需要 Apple Command Line Tools 中的 Swift 编译器，无需完整 Xcode、开发者会员或第三方依赖。

```sh
./test.sh
./build.sh
```

构建产物：

- `build/今日收入.app`
- `build/今日收入-mac-arm64.zip`

将应用复制到“应用程序”后打开，从顶部菜单栏点击金额查看详情。首次启动会打开工资与作息设置。

构建脚本使用本机临时签名，未做 Developer ID 签名或 Apple 公证，适合自行构建使用。构建在临时目录完成，以避免文件提供程序附加 Finder 元数据干扰签名。

## 计薪规则

```text
日薪 = 月薪 ÷ 每月计薪天数
全天计薪时长 = 工作时段 − 不计薪的午休时长
已计薪时长 = 已过的工作时间 − 已经过的不计薪午休时间
今日收入 = 日薪 × 已计薪时长 ÷ 全天计薪时长
```

默认月薪 5000、09:00–18:00、周一至周五、21.75 个计薪日，均为可修改的演示值。币种只改变单位，不换汇。午休默认关闭，旧配置升级后保持原计薪方式。启用后可选计薪或不计薪；不计薪时收入与计薪进度暂停、时薪按有效工作时长折算，全天日薪不变。午休必须在班次内且不能占满班次，支持跨午夜。暂不自动识别节假日。跨午夜班次归上班当天；设置改变后按新规则重新估算当天金额。这里的金额是估算，不代表实际发薪或到账。

## 数据与卸载

设置保存在本机 UserDefaults，应用 ID 为 `local.deskincome.card`。不上传工资，不读取银行或考勤数据。

卸载前如开启过开机启动，请从详情“更多”关闭，再退出并将应用移至废纸篓。
